MYSORE VOCATIONAL TRAINING CENTER — SCHOOL MANAGEMENT PORTAL
===============================================================

This is a professional responsive FRONT-END DEMO.

Included:
- Role-selection login page
- Student portal dashboard
- Staff workspace dashboard
- Administrator console
- Responsive sidebar navigation
- Attendance, courses, results, fees, timetable, notices
- Staff classes, grading, student alerts and attendance
- Admin enrollment, admissions, finance, staff activity and reports areas
- Role-based login routing: Student -> student.html, Staff -> staff.html, Admin -> admin.html

Demo login:
Any non-empty ID and password will work. The selected role controls the destination.

Important:
This package is a UI prototype. It does not contain a real database, secure authentication,
payment gateway, email/SMS service, or server-side authorization. For production use,
connect the screens to a backend/API and enforce permissions server-side.
