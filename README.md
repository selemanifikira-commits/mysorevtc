# Mysore Vocational Training Center — School Management System Demo

A front-end-only, responsive school management dashboard designed as a hosting-ready demo.

## Included modules
- Dashboard
- Student Management
- Student Admissions
- Staff Management
- Fees & Payments
- Academic Results
- Class Timetable
- Notice Board
- Email Center
- Responsive mobile navigation
- Demo modals and interactive forms
- WhatsApp routing for admission/help/contact actions

## Hosting
This is a static website. Upload `index.html`, `styles.css`, and `app.js` to GitHub Pages, Netlify, Vercel, cPanel, or another static host.

## Important
This is a front-end demo only. It does not store real student records, authenticate users, send actual emails, process payments, or provide a real database/backend.

For a production version, connect the UI to a secure backend/database and add authentication, roles/permissions, audit logs, backups, validation, and real email/SMS/payment integrations.
